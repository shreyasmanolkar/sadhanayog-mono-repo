# Archive

Closed issues normally stay in [`../issues`](../issues) as `canceled` or `duplicate`.
IDs are never reused, so a file is never deleted.

Move an issue here only when the `issues/` directory needs to shrink and the file
must still exist for history, links, and lint. The filename remains `SY-NNNN.md`.
`track lint` loads both directories.

Do not put a `README` issue here — only `SY-NNNN.md` files are issues.
