# Agent Note: Vite SPA, not SSR

Status: proposed

## Problem

The command center is a private authenticated desk. SSR/SEO frameworks add a
second server.

## Proposal

Use a client-rendered React/Vite application served as Worker static assets.
TanStack Router, Query, and Form on the client.

## Rationale

No public SEO requirement. The Worker is already the server boundary.

## Alternatives considered

- **TanStack Start / Next.js:** rejected for now; they duplicate server
  responsibilities. Revisit only if a public learning surface needs SEO.

## Affected components

`apps/web`, Worker asset binding.
